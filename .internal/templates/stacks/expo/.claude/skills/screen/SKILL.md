# Skill: Screen Scaffolder

Scaffold a full screen with Expo Router conventions.

## Patterns

- Export default function component
- File-based routing in `app/`
- Layout files use `Stack.Screen` or `Tabs` configuration
- Auth screens in `(auth)/` group
- Main screens in `(tabs)/` group
- Colors from `@constants/colors`
- Icons from `@expo/vector-icons`
