# Quick Start

## 1. Choose your stack

This project template supports multiple stacks. See the `stacks/` directory for available options.

## 2. Install dependencies

```bash
cd your-stack-directory
<follow the stack's README for installation>
```

## 3. Start development

Refer to your specific stack's `README.md` for development instructions.

## Commands Reference

| Command | Purpose |
|---------|---------|
| `{{START_CMD}}` | Start development server |
| `{{TYPECHECK_CMD}}` | Type check |
| `{{LINT_CMD}}` | Lint |
| `{{TEST_CMD}}` | Run tests |
